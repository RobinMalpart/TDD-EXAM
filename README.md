# TDD-EXAM

**TDD-EXAM** est un projet démontrant la résolution du problème des **N-Reines** en utilisant **Test-Driven Development (TDD)**.

## 📁 Structure du projet

```
TDD-EXAM/
├── ExamApp/          # Application console principale
└── ExamApp.test/     # Projet de tests unitaires avec xUnit
```

## ⚙️ Instructions pour lancer le projet

1. **Restaurer les packages** :
   ```bash
   dotnet restore
   ```
2. **Compiler la solution** :
   ```bash
   dotnet build
   ```
3. **Exécuter l'application** :
   ```bash
   cd ExamApp
   dotnet run
   ```
4. **Exécuter les tests unitaires** :
   ```bash
   cd ../ExamApp.test
   dotnet test
   ```

## 🛠️ Environnement requis

- **.NET 5.0** ou version ultérieure
```
